Электронный документооборот без лишней бюрократии

1ОС.ЭДО.Легаси — приложение для обмена документами с оператором ЭДО Доки (компания «Астрал») из вашей учётной системы: УПД контрагентам в одно касание, счёт-фактуры по входящим документам и подписание в веб-интерфейсе Доки.

Внедрение с минимальным вмешательством

Приложение подключается к учётной системе через динамически подключаемый модуль. Это снижает риски для рабочей базы и ускоряет запуск: не нужны глубокие доработки типовой логики.

Модуль подключается к конфигурации штатными механизмами платформы. Основная учётная функциональность остаётся нетронутой, а обмен ЭДО выносится в отдельный контур приложения.

  • Меньше точек соприкосновения с обновлениями конфигурации
  • Проще сопровождение и перенос между базами

Архитектура рассчитана на быстрое добавление нового функционала и сопровождение широкого спектра конфигураций, в том числе снятых с официальной поддержки производителя.

  • Гибкое наращивание сценариев без «монолитных» вмешательств
  • Актуальные требования законодательства — через обновления приложения

Уже сейчас доступны современные сценарии на модифицированных конфигурациях, включая обмен УПД и работу с кодами маркировки. В планах — расширение на обмен электронными транспортными накладными (ЭТрН).

  • Маркировка и смежные форматы
  • Дорожная карта под логистические документы
